TH AEGIS INTELLIGENCE — AI CREATIVE STUDIO

ARQUIVOS
- index.html: site futurista e responsivo
- netlify/functions/generate.mjs: função segura de geração de imagem/vídeo
- netlify.toml: configuração Netlify
- package.json: dependência da API Hugging Face

IMPORTANTE: não existe garantia de geração ilimitada e grátis. A geração depende do token, cotas, disponibilidade do provedor e dos modelos. Nunca coloque o token no index.html nem no GitHub.

CONFIGURAÇÃO
1. Crie uma conta no Hugging Face: https://huggingface.co/
2. Crie um token com permissão de Inference Providers em https://huggingface.co/settings/tokens
3. No Netlify, abra Site configuration > Environment variables (ou Configuration > Environment variables).
4. Adicione HF_TOKEN com o token como valor. Não compartilhe esse token no chat.
5. Publique novamente o site a partir do GitHub.
6. Confirme que generate.mjs está em netlify/functions/generate.mjs.

Atenção: provedores e modelos podem mudar disponibilidade, exigir permissões/créditos ou não aceitar todas as proporções. A função devolve mensagens de erro quando o provedor falha.
